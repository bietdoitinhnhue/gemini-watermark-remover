FAQ

Useful answers, up front.

Are my images uploaded to a server?+

No. The image workflow runs in the browser on the device that opened this page.

Which image formats are supported?+

JPG, PNG and WebP are supported. You can select more than one image at a time.

What happens with unsupported files?+

The workspace accepts JPG, PNG and WebP. Files outside those formats are kept out of the image queue.

Will every source image have the same result?+

Results depend on the supported source format and watermark pattern. The tool returns the best result it can produce and surfaces any relevant status.
